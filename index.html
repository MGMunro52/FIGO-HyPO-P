HyPO-P Ovarian Physiology Demo

Updated ovarian teaching demo with tubal pickup and a more rule-based endometrial response. Sequence: FSH → dominant follicle → LH surge / ovulation → fimbrial pickup → corpus luteum → luteolysis / menstruation.

BUILD V3.1 · TUBAL PICKUP + RULE-BASED ENDOMETRIUM
Tap the hormone labels in the pituitary or use the buttons. On phones, the explanation remains in the bottom popup so it stays visible with the figure.

Start state

This teaching view starts in the late follicular phase. Use FSH first to highlight the dominant follicle and estradiol effect on the endometrium. Then use LH surge / ovulation, followed by Corpus Luteum, then Luteolysis / Menses.

What changed in this version: the released oocyte is now directed toward a fallopian tube / fimbrial pickup, and the endometrium follows a more rule-based progression: follicular proliferative → thick pre-luteal midcycle → lush secretory luteal → menstruation.
